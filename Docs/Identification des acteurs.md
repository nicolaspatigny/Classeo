# Identification des acteurs

## 1. Présentation

L’application implique trois principaux types d’acteurs. Chaque acteur dispose de droits et de fonctionnalités adaptés à son rôle dans le suivi pédagogique.

## 2. Élève

L’élève est l’utilisateur qui suit une formation.

Il peut :

* Consulter son calendrier et son emploi du temps ;
* Consulter ses cours ;
* Consulter ses notes ;
* Consulter sa promotion ;
* Consulter les informations liées à son cursus.

L’élève dispose principalement de droits de consultation.

## 3. Professeur

Le professeur est responsable de l’enseignement des cours qui lui sont attribués.

Il peut :

* Consulter son emploi du temps ;
* Consulter les promotions auxquelles il enseigne ;
* Consulter ses cours ;
* Ajouter ou supprimer des cours selon ses droits ;
* Saisir et modifier les notes ;
* Enregistrer les absences des élèves.

## 4. Administratif

L’administratif est responsable de la gestion globale de l’application et de la structure pédagogique.

Il peut :

* Gérer les élèves et les professeurs ;
* Gérer les inscriptions ;
* Gérer les promotions et les filières ;
* Gérer les cursus ;
* Gérer les cours et les emplois du temps ;
* Affecter les élèves aux promotions ;
* Affecter les élèves et promotions aux cours ;
* Affecter les professeurs aux cours.

Il dispose des **droits de gestion les plus larges**.

## 5. Tableau récapitulatif

| Acteur        | Rôle principal                     | Niveau d'accès               |
| ------------- | ---------------------------------- | ---------------------------- |
| Élève         | Suivi de sa scolarité              | Consultation                 |
| Professeur    | Gestion pédagogique de ses cours   | Consultation et modification |
| Administratif | Gestion globale de l'établissement | Administration               |
